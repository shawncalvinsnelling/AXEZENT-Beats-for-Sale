# AXEZENT: 50 beat patterns, listening reference points and exact section durations

**Nov 8, 2026 | Scope:** the **50 existing original AXEZENT instrumental review arrangements**. Full 200-song catalog preserved; only the selected first 50 are currently presented.

**What this comparison means:** Reference songs below are **recognizable style touchstones**, selected from regional descriptions, rhythm families, assigned BPM/keys, and the original MIDI generator's code. **We did not obtain or compare reference masters, official FL Studio piano rolls, individual drum stems, audio fingerprints, or exact note sequences from those songs.** A reference here is **not** a claim that an AXEZENT beat sounds identical to, copies, or statistically matches that recording. City of a beat does not dictate a single sound.

**What the duration numbers mean:** Each section's exact length is calculated as `endSeconds − startSeconds` from that specific arrangement. Rounded to 0.1 second for display. The **website popup** now displays each of these values **immediately under the section name**, with the section's start/end time and a tap-to-seek control. These are bar-derived blueprint times and may differ by a fraction of a second from MP3 codec padding.
